# PLAN-01 — Kế hoạch

**Nền tảng:** MVP · Mobile + Web

## Navigation

Ba tab: **Mục tiêu**, **Sự kiện**, **Lịch biểu**.

## Mục tiêu

Tuần hiện tại, progress, checkbox hoàn thành, thêm nhanh, sửa/xóa.

## Sự kiện

Danh sách sắp tới, giờ bắt đầu/kết thúc, địa điểm, thêm/xóa.

## Lịch biểu

Danh sách theo ngày/giờ, trạng thái, thêm/xóa.

## States

Loading độc lập theo từng tab, Empty, List, Error từng tab. Một API lỗi không
được làm mất dữ liệu của hai tab còn lại.
