# PLAN-03 — Form sự kiện

**Nền tảng:** MVP · Mobile + Web

## Fields

Tên sự kiện, ngày, giờ bắt đầu, giờ kết thúc, địa điểm, ghi chú.

## Validation

Tên bắt buộc; giờ kết thúc không trước giờ bắt đầu; cảnh báo xung đột nếu có.

## States

Create, Edit, Saving, Conflict warning, Delete confirmation.
