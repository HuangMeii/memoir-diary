# Shared Components — Component page cho Figma

Tạo component trước khi vẽ màn hình:

- App shell: AppBar, Sidebar, BottomNavigation, Breadcrumb.
- Form: TextField, Textarea, NumberField, DatePicker, TimePicker, Select.
- Feedback: Snackbar, Toast, Dialog, Banner, Skeleton, EmptyState, ErrorState.
- Journal: MoodWeatherPicker, MonthGridCell, Legend, QuoteCard, ReflectionBox,
  PhotoThumbnail.
- Planning: TabBar, TodoRow, EventRow, ScheduleRow, StatusBadge.
- Health: MetricCard, Chart, ChartTooltip.

Mỗi component có variant `Default`, `Hover`, `Pressed`, `Focused`, `Disabled`,
`Loading` khi phù hợp; kích thước tương tác tối thiểu 44×44 px.
