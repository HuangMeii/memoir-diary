# LIB-01 — Ghi chú nhanh

**Nền tảng:** MVP · Mobile + Web

## Bố cục

- AppBar “Ghi chú nhanh”.
- Input thêm nhanh và nút `+`.
- Danh sách card ghi chú: nội dung, ngày tạo, pin, edit, delete.
- Empty state có CTA “Tạo ghi chú đầu tiên”.

## States

Loading, Empty, List, Delete confirmation, Error.

## Responsive

Mobile input dính phía trên; web input tối đa 720 px và list rộng 2 cột khi
đủ không gian.
