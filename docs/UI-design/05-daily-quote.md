# HOME-02 — Câu nói và phản tư

**Nền tảng:** MVP · Mobile + Web

## Thành phần

- Quote từ kho.
- Quote thứ hai hoặc lời nhắn của người dùng.
- Nút “Đổi câu”.
- Textarea “Bạn nghĩ gì về hai câu này?”.
- Textarea “Lời nhắn cho bản thân”.
- Nút lưu riêng cho phản tư và lời nhắn.
- Link “Xem lịch sử”.

## States

Chưa có self-message, đang đổi câu, đang lưu, lưu thành công, quote đã bị xóa.

## Prototype

“Xem lịch sử” → `LIB-02`; lưu self-message → cập nhật `LIB-03`.
