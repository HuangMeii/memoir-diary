# HEALTH-01 — Nhập sức khỏe

**Nền tảng:** MVP · Mobile + Web

## Fields

Ngày, bước chân, phút tập luyện, nước (ml), giấc ngủ (giờ), cân nặng (kg),
ghi chú.

## Bố cục

Mobile nhóm từng field theo card; web dùng grid 2 cột và đặt nút lưu ở cuối
card sticky nhẹ.

## Validation

Chỉ nhận số hợp lệ, hiển thị đơn vị ngay trong label/helper, không tự thay
đổi giá trị người dùng nhập.
