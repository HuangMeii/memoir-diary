# Memoir UI Design — Figma Screen Briefs

Thư mục này là bộ brief thiết kế theo **từng trang/màn hình**, dùng trực tiếp
để tạo page và frame trong Figma. Không nên thiết kế tất cả trong một canvas
duy nhất.

## Quy ước

- `MVP`: chức năng đã có backend/Flutter và nên thiết kế trước.
- `ROADMAP`: đã có đặc tả nhưng chưa triển khai.
- Mỗi file tương ứng ít nhất một page trong Figma.
- Mỗi màn hình phải có frame Mobile 390×844 và Web 1440×1024; thêm Tablet
  khi bố cục khác đáng kể.
- Mỗi file cần vẽ các state: Default, Loading, Empty, Error và Success.
