# 08 — Kho câu động viên / giáo dục (100 câu) — dữ liệu seed

Tài liệu này chứa bộ **100 câu** dùng để seed bảng `quotes`. Nội dung sưu tầm từ mạng xã hội, sách và các nguồn công khai; phân loại theo `category`.

**Trường dữ liệu**: `text` (nội dung), `author` (tác giả), `source` (nguồn), `category`.

**Categories**: `động viên`, `giáo dục`, `chánh niệm`, `biết ơn`, `kiên trì`, `bản thân`, `quan hệ`, `tài chính`, `sức khỏe`, `sáng tạo`.

> Ghi chú: một số câu là bản dịch/phiên bản phổ biến trên mạng; tác giả có thể là "Khuyết danh" nếu không xác định. Có thể chỉnh sửa qua API CRUD.

## Cách seed vào database

1. Chuyển 100 dòng trên thành danh sách JSON hoặc insert trực tiếp trong `app/seed/quotes_100.json`.
2. Script `python -m app.seed.seed` sẽ:
   - Bỏ qua nếu `text` đã tồn tại (idempotent).
   - Gán `user_id = NULL` (câu hệ thống) để mọi người dùng đều dùng chung.
3. Người dùng có thể thêm/sửa/xóa câu riêng qua API `/quotes` (bản ghi có `user_id`).
